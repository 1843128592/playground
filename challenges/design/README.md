# 设计：新人参与流程卡片

## 目标

为新人设计一份参与流程卡片，说明从 Fork、提交个人介绍 PR、审核合并到发送和接受组织邀请的过程。工具不限。

## 范围

交付可查看的预览和设计说明，可附可编辑源文件或链接。卡片应适合手机阅读，不要求设计完整品牌体系。

## 验收清单

- [ ] 包含参与步骤和清晰的阅读顺序。
- [ ] 清楚说明个人介绍 PR 审核并合并后，我们向 PR 提交者的 GitHub 账号发送邀请，再由对方接受。
- [ ] 手机尺寸下文字清晰、对比度足够，不单靠颜色表达状态。
- [ ] README 提供预览、设计取舍、查看方法及字体、图片或其他素材的来源与许可。

## 提交

先在 Issue 中认领并与负责人确认任务。成果放在 `experiments/<GitHub 用户名>/<项目名>/`，附项目 README，通过 PR 关联任务。可以使用 AI 辅助，但需要解释实现或设计，注明来源并亲自验证。

完成基础要求后可以自行扩展，扩展内容不作为本挑战的必需项。
