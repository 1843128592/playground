# 入门挑战

选一个感兴趣的方向即可，不要求做完所有任务。技术栈不限，先与负责人确认目标，再提交一个能演示、能解释的成果。

| 方向 | 第一个挑战 | 主要练习 |
| --- | --- | --- |
| [前端](frontend/README.md) | 个人介绍页面 | 页面结构、交互、响应式与基本可访问性 |
| [后端](backend/README.md) | 内存待办 API | HTTP、输入校验、错误处理与验证 |
| [AI](ai/README.md) | 有来源的新人问答实验 | 问题设计、依据、评估与限制 |
| [设计](design/README.md) | 新人参与流程卡片 | 信息层级、流程表达与设计说明 |

## 如何提交

1. 在任务 Issue 下认领；没有对应 Issue 时，通过“挑战认领”模板提出所选任务，等待负责人确认。
2. 新建 `experiments/<GitHub 用户名>/<项目名>/`，存放自己的成果及 README。
3. 对照方向文档中的验收清单检查，提交 PR，说明验证结果。
4. 根据 Review 修改，并解释关键做法。

负责人可以基于这些示例调整任务。以双方在 Issue 中确认的验收要求为准。遇到困难可以缩小范围或请求帮助，无需为了提交而加入自己解释不了的功能。
