# 前端：个人介绍页面

## 目标

做一个展示昵称、兴趣方向和学习目标的个人页面。可使用 HTML / CSS / JavaScript，也可以使用熟悉的框架。

## 范围

页面内容可使用虚构信息，不直接公开个人联系方式。至少加入一个可操作的交互，例如切换主题或展开介绍。

## 验收清单

- [ ] 页面结构清晰，包含昵称、方向和学习目标。
- [ ] 在窄屏与桌面宽度下都可阅读，没有明显横向溢出。
- [ ] 至少一个交互可正常使用，按钮或链接支持键盘操作。
- [ ] README 写明查看或启动步骤，提供两种宽度的截图与验证结果。

## 提交

先在 Issue 中认领并与负责人确认任务。成果放在 `experiments/<GitHub 用户名>/<项目名>/`，附项目 README，通过 PR 关联任务。可以使用 AI 辅助，但需要解释实现或设计，注明来源并亲自验证。

完成基础要求后可以自行扩展，扩展内容不作为本挑战的必需项。
