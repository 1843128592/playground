# AI：有来源的新人问答实验

## 目标

选取本仓库 README、贡献指南和挑战说明作为材料，做一个能依据材料回答新人问题的小实验。可使用提示词、脚本或已有工具，不要求搭建完整 RAG 系统。

## 范围

准备至少 5 个问题，其中至少 1 个材料内没有答案。记录输入材料、问题、回答、引用位置与人工评价；缺少依据时应明确说明无法从材料确定。

## 验收清单

- [ ] 至少 5 个问题和完整结果记录，覆盖材料内问题与超出材料的问题。
- [ ] 材料内回答能指出对应文件和章节，没有编造入组承诺或规则。
- [ ] 材料外问题明确承认依据不足，记录错误、失败案例或局限。
- [ ] README 写明使用的工具或模型、实验日期、可复现步骤及人工核查方法；不提交 API Key。

## 提交

先在 Issue 中认领并与负责人确认任务。成果放在 `experiments/<GitHub 用户名>/<项目名>/`，附项目 README，通过 PR 关联任务。可以使用 AI 辅助，但需要解释实现或设计，注明来源并亲自验证。

完成基础要求后可以自行扩展，扩展内容不作为本挑战的必需项。
