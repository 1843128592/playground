# 后端：内存待办 API

## 目标

使用熟悉的语言实现一个待办列表 API。数据保存在内存即可，不要求数据库、登录或部署。

## 范围

实现 GET /todos、POST /todos、PATCH /todos/:id 和 DELETE /todos/:id。待办包含 id、title、completed；重启后数据丢失应在 README 中说明。

## 验收清单

- [ ] 能够列出、新建、修改和删除待办。
- [ ] title 为非空字符串，completed 为布尔值；错误类型和畸形 JSON 不会导致服务崩溃。
- [ ] 不存在的 id 返回 404，非法输入返回明确的 4xx 错误，成功响应合理使用状态码。
- [ ] README 包含启动步骤和可复现的请求示例，覆盖正常流程、非法输入与不存在的 id。

## 提交

先在 Issue 中认领并与负责人确认任务。成果放在 `experiments/<GitHub 用户名>/<项目名>/`，附项目 README，通过 PR 关联任务。可以使用 AI 辅助，但需要解释实现或设计，注明来源并亲自验证。

完成基础要求后可以自行扩展，扩展内容不作为本挑战的必需项。
